# Mohana Krishna — Portfolio

A responsive personal portfolio built for the Finlatics Web Development Internship. The site presents selected AI, computer-vision, and web projects with accessible navigation, motion-aware interactions, and custom CSS visuals.

## Run locally

```bash
npm install
npm start
```

Then open the local URL printed by `serve`.

## Built with

- Semantic HTML
- Tailwind CSS utilities for responsive layout and custom CSS for the visual system
- Vanilla JavaScript for mobile navigation, reveal interactions, and the contact form
- Mobile-first breakpoints with reduced-motion accessibility support
