# Mohana Krishna — Portfolio

A responsive personal portfolio built for the Finlatics Web Development Internship. The site presents selected AI, computer-vision, and web projects with accessible navigation, motion-aware interactions, and custom CSS visuals.

## Run locally

```bash
npm install
npm start
```

Then open the local URL printed by `serve`.

## Built with

- Semantic HTML
- Modern CSS with responsive layouts and reduced-motion support
- Vanilla JavaScript for navigation and reveal interactions
